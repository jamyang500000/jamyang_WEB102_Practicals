Social Media API Documentation

This is the documentation for the Social Media API, a RESTful API for a platform.

Users

GET /users

Get a list of all users with pagination

Query Parameters

Parameter Type Description
page Number Page number (default: 1)
limit Number Number of users per page (default: 10)

Response

{
  "success": true,
  "count": 2,
  "page": 1,
  "total_pages": 2,
  "pagination": {
    "next": {
      "page": 2,
      "limit": 10
    }
  },
  "data": [
    {
      "id": "1",
      "username": "traveler",
      "full_name": "Karma",
      "profile_picture": "https://example.com/profiles/traveler.jpg",
      "bio": "Travel photographer",
      "created_at": "2023-01-15"
    }
  ]
}
GET /users/:id

Get a specific user by ID

Parameters

Parameter Type Description
id String User ID

Response

{
  "success": true,
  "data": {
    "id": "1",
    "username": "traveler",
    "full_name": "Karma",
    "profile_picture": "https://example.com/profiles/traveler.jpg",
    "bio": "Travel photographer",
    "created_at": "2023-01-15"
  }
}
POST /users

Create a new user

Request Body

{
  "username": "new_traveler",
  "email": "new@example.com",
  "password": "securepassword",
  "full_name": "New Traveler",
  "bio": "Adventure seeker"
}

Response

{
  "success": true,
  "data": {
    "id": "4",
    "username": "new_traveler",
    "full_name": "New Traveler",
    "email": "new@example.com",
    "profile_picture": "default-profile.jpg",
    "bio": "Adventure seeker",
    "created_at": "2023-03-20"
  }
}
PUT /users/:id

Update an existing user

Request Body

{
  "full_name": "Updated Name",
  "bio": "Updated bio"
}

Response

{
  "success": true,
  "data": {
    "id": "1",
    "username": "traveler",
    "full_name": "Updated Name",
    "bio": "Updated bio",
    "created_at": "2023-01-15"
  }
}
DELETE /users/:id

Delete a user

Response

{
  "success": true,
  "data": {}
}

Posts

GET /posts

Get a list of all posts with pagination

Response

{
  "success": true,
  "count": 4,
  "page": 1,
  "total_pages": 1,
  "pagination": {},
  "data": [
    {
      "id": "1",
      "caption": "Beautiful sunset in the mountains!",
      "image": "https://example.com/posts/sunset.jpg",
      "user_id": "1",
      "created_at": "2023-03-01",
      "user": {
        "id": "1",
        "username": "traveler",
        "full_name": "Karma",
        "profile_picture": "https://example.com/profiles/traveler.jpg"
      }
    }
  ]
}
GET /posts/:id

Get a specific post by ID

POST /posts

Create a new post (requires X-User-Id header)

Headers

X-User-Id: 1

Request Body

{
  "caption": "My new post!",
  "image": "https://example.com/image.jpg"
}
PUT /posts/:id

Update an existing post (requires X-User-Id header, only post owner can update)

DELETE /posts/:id

Delete a post (requires X-User-Id header, only post owner can delete)

Content Negotiation

By default, the API returns responses in JSON format. To get XML responses, set the Accept header to application/xml.

Example

curl -H "Accept: application/xml" http://localhost:3000/users
